# Staff Dashboard Pages

This package adds the complete staff/lecturer page structure matching the staff navigation:

- Dashboard
- Home
- Application: To Review, All Applications
- Course: My Courses, Course Materials, Course Forum, Discussion
- Quiz: Create Quiz, Manage Quiz, Quiz Results
- Notifications: Send Notification, History
- Studio: Live Stream, Activity Stream, Meetings, Messaging
- Grade Book: Continuous Assessment, Exam Mark Entry Sheet, Tabulation Sheet
- Assignment: Create Assignment, All Assignments, Grade Submissions
- Payroll: Pay Slip, Payment History
- Profile: Profile System, Profile & Biodata
- Hostel & Accommodation
- SIWES: IT Supervisor Dashboard
- HR: Personal HR, Approval & Promotion Tracker, Leave & Absence Request

The pages are intentionally API-neutral. Connect the existing backend endpoints where available rather than inventing new endpoints.
